# Change Log

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-10-05

### Changed
- Updated to Shardy 1.3.0 (`Task` type replaced by `CommandHandler`)
- Updated dependencies, fixed npm audit issues
- Node.js >=24 and npm 11.12.1 requirements, `@types/node` 24 (aligned with Shardy 1.3.0)
- Note: with `ENV=production` Shardy 1.3.0 logs only warnings and errors, to files

### Removed
- Unused `ip` and `@types/ip` packages
